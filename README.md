# 방배 고양이카페 (Bangbae Cat Cafe)

브라우저에서 바로 하는 고양이카페 경영 게임이에요. 파일 하나(`cat-cafe.html`)로 동작하며 설치할 것이 없어요.

## 플레이 방법

`cat-cafe.html`을 내려받아 브라우저(PC, 휴대폰)로 열면 돼요. 진행 상황은 브라우저에 자동 저장돼요.

## 주요 기능

- **카페 운영**: 손님 안내, 주문 받기(직접), 직원 자동 서빙, 화장실과 청소부, 손님 유형·이벤트·일일 미션
- **고양이**: 이름 짓기, 레벨과 특기, 희귀 고양이, 소품, 캣타워 놀이, 쥐·도마뱀 사냥
- **번식**: 캣타워에 함께 올린 암수 고양이 사이에서 아기 고양이가 태어나고, 털색과 무늬를 부모에게 물려받아요 (최대 16마리, 입양 보내기 가능)
- **장기 목표**: 카페 등급과 주간 평가, 가게 확장 공사 4단계, 계절(봄·여름·가을·겨울) 한정 메뉴와 이벤트, 길고양이 구조, 고양이 사진첩, 업적
- **연출**: Web Audio로 만든 BGM과 효과음, PC·휴대폰 화면 자동 맞춤, 다크 모드
